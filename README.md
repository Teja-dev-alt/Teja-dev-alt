### 📚 KursusKu

Aplikasi pendaftaran kursus dengan tiga tabel utama dan relasi M : N:

```
COURSES (1) ──< ENROLLMENTS >── (1) PARTICIPANTS
```

Satu peserta tidak bisa mendaftar dua kali pada kursus yang sama, dijaga dengan `UNIQUE (participant_id, course_id)`.
